# Currency Converter 💱
A simple currency converter built using *HTML, CSS, and JavaScript*.

## Features
* Convert between different currencies
* Live exchange rates using an API
* Dynamic country flags
* Swap currencies
* Simple and responsive UI

## Technologies
* HTML
* CSS
* JavaScript
* Fetch API
* Currency API
* Flags API

## How to Run
1. Clone the repository.
2. Open the project in VS Code.
3. Run index.html using Live Server.
